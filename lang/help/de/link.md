# Was «alle mit dem Link» bedeutet

Ein Board oder eine Aktivität ist für alle erreichbar, die den Link kennen. Die Kurzwörter sind kurz, damit eine Klasse sie leicht eintippen kann; sie sind kein Geheimnis. Schreib deshalb nichts auf ein Board, was nicht jede Person mit dem Link lesen darf.

Geschlossen heisst lesbar, aber nicht mehr beschreibbar. Archiviert heisst für die Klasse unsichtbar.
