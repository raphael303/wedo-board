# Dokumente zur Nutzerverwaltung

Dieser Ordner enthält Kopien von Projektdokumenten aus dem Claude-Projekt «Tafula», damit sie neben dem Code
nachlesbar sind. Verbindlich ist die Fassung im Projekt; bauende Sitzungen ändern diese Kopien nicht, sondern
ersetzen sie, wenn sich die Fassung im Projekt ändert.

- `konzept-nutzerverwaltung.md`: Konzept der Nutzerverwaltung, Fassung 7 vom 2026-11-17 (Projektdokument
  `claude/konzept-nutzerverwaltung.md`), kopiert am 2026-11-19 in Etappe U0.
- `rechte-matrix.md`: Rechte-Matrix zu Fassung 7 (Projektdokument `claude/rechte-matrix-entwurf-2026-11-16.md`),
  kopiert am 2026-11-19 in Etappe U0.

Der Webserver liefert diesen Ordner nicht aus (`.htaccess` und `dev-router.php`).
